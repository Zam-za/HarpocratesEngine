# HarpocratesEngine
 deep-learning based edge AI architecture that challenges the efficiency of cloud-orientated defences in physical train infrastructures, considering hardware constraints and optimization strategies. The project concerns detecting attacks like DoS, Jamming and Stealthy Replay using simulated data from the STSRS dataset generated with stochastic dynamics and context-aware attack injection. The architecture to be built aims to perform in heterogeneous railway environments (hardware, network and infrastructure changes) providing statistics such as: detection rate, detection delays and latency that evaluate if the architecture is capable of running effectively on the edge of train-to-control system communications.
